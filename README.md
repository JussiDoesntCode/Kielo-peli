# Prinsessa Kielon metsäseikkailu 👑🌲

Puhelimella pelattava metsäpeli, jonka ideat keksii viisivuotias pelisuunnittelija.

## Pelin säännöt
- 👆 Pidä sormea ruudulla, niin Kielo kävelee sinne
- 🪙 🌸 💎 Kerää rahoja, kukkia ja timantteja
- 🐾 Näkymätön varjo vaanii, mutta sen tassunjäljet näkyvät maassa
- ✨ Ota kiinni keiju: varjo tulee näkyviin, eikä se voi satuttaa
- ❤️ Kolme sydäntä

## Tiedostot
- `index.html` on koko peli yhdessä tiedostossa
